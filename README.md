# Physimos
### Interactive 3D world with integrated physics simulations - OpenGL & C/C++



## Build & run instructions


### System dependencies

(updated 2026-05-22 -- ubuntu 24.04)

- CMake (version 3.28 or higher)
    - `sudo apt install cmake`, then verify versoin using `cmake --version`
- ninja
    - `sudos apt install ninja-build`
- Other compiler toolchain
    - `sudo apt install build-essential gdb pkg-config`
- graphics & windowing
    - `sudo apt install libdrm-dev libgl-dev libwayland-dev libegl-dev libdecor-0-dev`


### VS code extensions

- CMake Tools (Microsoft)
- C/C++ (Microsoft)
- C/C++ DevTools (Microsoft)
